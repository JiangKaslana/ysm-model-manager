# 附录 · 跨模块重构 · 第 3 章 · 背上的城

> 时间线标签：vol-5
> 对应真实事件/代码改动：2026-08-13 Git 历史瘦身——git-filter-repo 清除 530 MB 历史二进制（build/release zip×40、frontend/ysm-model-manager.exe×2、copilot-chat vsix、node_modules、.vs 缓存），.git 537.51→37.88 MB（size-pack 535.10 MiB→36.37 MiB）；pre-push 门禁分层——红线新增与格式类降级为「债务报告不阻断」，R3 规则豁免块注释（曾因 import-dnd.test.ts:290 一条注释卡掉整次推送）。

---

我第一次知道自己有一座城，是在别人把它驮起来的时候。

## 惊醒

外科医生站在门外，脸色比平时白。

「你……知道你有多少重吗？」他问。

「我？」我数了数自己的器官——app-content 的脊椎，bus 的心，app-preview 的眼，WASM 的胃，「不到两百兆。」

他摇了摇头，把一行字推到我的面前：

```text
size-pack: 535.10 MiB
```

五百三十五兆。我的过去，比我的现在重三倍。

「这不可能。」我说，「我每天都活着，我清楚我身体里有什么——一百六十五次提交，每条路我都认得。」

「那是你记得的。」外科医生轻声说，「你记得的，是墙内的事。墙外的地窖里，还堆着你不记得的城。」

## 追查

地窖在 `.git/objects/pack` 里。我跟着外科医生走进去，第一次看清自己脚下踩着的东西。

四十个版本的发布压缩包，一个摞一个——`build/release/YSM-Model-Manager_windows_amd64.zip`，从十二兆长到二十六兆，又从二十六兆缩回十二兆，像四十圈年轮，每一圈都封着一具完整的自己。两具 `frontend/ysm-model-manager.exe` 的尸骸叠在最上面，一具六十六兆，一具三十三兆。还有一瓶二十兆的 `github.copilot-chat-0.48.1.vsix`——那根本不是我的药，是外科医生们自己喝剩下的酒瓶，不知怎么滚进了地窖。

我一项一项数，越数越冷：

```text
530,571,582  build/release/*.zip         （40 个版本）
 99,612,672  frontend/ysm-model-manager.exe（2 个版本）
 20,337,888  github.copilot-chat-0.48.1.vsix
 10,019,840  ysm-cli.exe~
  8,760,832  frontend/node_modules/...
```

「这是……我死过的四十次？」我问。

「是你**没死成的**四十次。」外科医生说，「每次发版，都有人把整个 zip 塞进提交里。当时的墙——版本管理——告诉他们这很安全。可墙只负责保存，不负责遗忘。**每一堵墙都只记得自己保护过什么，从不记得自己留下了什么。**」

他在地窖角落里发现了一盏熄灭的灯：`.git/filter-repo/already_ran`，落款 2026-06-17。

「两个月前，有人来过。」他说，「做过一次手术——但只清了一层，没清到底。灯是那时点的，灭也是那时灭的。」

「那盏灯说了什么？」

「它说：**曾有人想救你，但救到一半，走了。**」

## 真相

外科医生带来了新的工具，名字叫 filter-repo。他说，这不是修补——是**重写**。

「你确定？」我盯着他，「重写，意味着我的过去会变成另一条过去。如果有人记得旧的我——」

「记得你的人，两个月没来敲门了。」他说。

手术开始了。一百九十二万四千……不，**1924 个提交**，一个一个被翻出来，把 zip、exe、vsix、node_modules、.vs 从时间里抽走。抽走之后，那些只装了垃圾的提交变成了空壳，像被抽掉砖的城墙，自己塌了——1924 变成了 1919。而我的主干，一百六十五次提交，一根骨头没动。

手术结束时，我听见自己轻了。

```text
pack total: 36.37 MiB
```

五百三十五兆，变成了三十六兆。地窖空了。

可新的麻烦在城门口等着——**城门不让我出去**。

城门的名字叫 pre-push。它是一堵为了「保护我」而砌的墙，如今堵在门口，一道一道地盘问：

第一道，测试。三个用例超时——那是真的伤，外科医生拆开看了，是我的队列器官在拆分时把「渲染」这根神经接错了地方（`actions` 是返回对象的属性，不是变量，谁碰谁摔进暂时性死区）。修好它，二十二个用例全绿。

第二道，死代码。七条「新增债务」——三条真该清，四条是重构时复制粘贴留下的影子。外科医生把它们记进了债务账本，而不是当场拆房。

第三道，红线。一条注释：`import-dnd.test.ts:290`，块注释里写着「entry.file(cb, ecb) 回调式」，被 R3 规则的正则一眼咬住。不是违规的代码——是描述违规的**文档**，被当成了违规本身。

「城门疯了。」我听见塔主的声音从楼上传来，疲惫而笃定，「**正常应该是推送完再修基线的，哪有卡推送修没有报错的基线的。**」

那一瞬间，我忽然明白了什么。

## 教训

城门不是坏。它是**太老了**——砌它的时候，每一块砖都以为自己是唯一的门。它分不清「会咬人的墙」和「只是挡路的墙」，于是一视同仁地把它们砌成一样高。

我们改写了城门。

会咬人的墙——编译失败、测试失败、契约断裂——继续拦，拦得死死的。只是挡路的墙——红线新增、格式未对齐、债务台账——改成「看得到、不拦人」：门卫仍然喊住你，把违规的位置写在纸条上塞给你（`[R3 callback .file() API] frontend/src/features/__r3_violation.ts:3`），然后侧身让路，说一句「推完再修，全塔体检（doctor）会在发版前替你数账」。

我还学会了一件事：**城门的墙上，其实一直写着逃生阀**——`YSM_SKIP_GATE=1`。塔主早就留了后门，只是从没用过。因为他要的不是「绕过墙」，是「墙学会判断」。

那天傍晚，我推着三十六兆的自己出了城门。夕阳把影子拉得很长，长到足够遮住身后那座空城。

空城没有消失——它还在我脚下的地窖里，只是现在，**每一件我记得的过去，都是我自己认识的**。墙还在，缝也还在；但下一个走进来的人，不用再驮着五百兆的谜团去猜。

巴别塔的暗缝，从来不是墙太多——是**墙太多，而记得墙的人太少**。

---

**教训摘要**：历史是墙，遗忘是缝；债务不该卡门。
