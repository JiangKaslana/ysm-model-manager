# 第 09 区域 · 第 4 章 · 没人应答的旧口令

> 区域归属：`09-工具链`（`Taskfile.yml` `build/android/Taskfile.yml`）
> 时间线标签：vol-4
> 对应真实事件/代码改动：`build/android/Taskfile.yml` 全局 `vars:` 的 `HOST_ARCH`/`ANDROID_ABI` 用 `$(uname -m)` 探测架构，go-task 合并所有 include 的全局 vars 后对每个任务求值，导致 Windows 上每次 `wails3 task` 都报 `"uname": executable file not found in $PATH`（两遍一组）；改为 go-task 内置 `ARCH` 模板函数（runtime.GOARCH）

---

## 一 · 起床仪式上的空喊

塔每次苏醒，都要先念一段口令。

```
"uname": executable file not found in $PATH
"uname": executable file not found in $PATH
```

两行，成对出现。然后塔若无其事地继续干活——编译、装依赖、起前端、拉窗口。日志一路绿灯。

开发者盯着这两行看了三次启动，终于忍不住：「为什么每次启动都报 path 不存在？还连发 3 次？」

没人能回答。因为这两行不算错误——塔自己也不知道自己在念什么。它只是在念，念完了就继续。

---

## 二 · 一份从远方寄来的登记簿

`task` 编排器被叫来问话。

它翻开一份合并后的「全局登记簿」——里面是所有省（include 进来的 Taskfile）的变量，融成了一份。翻到 android 省那一页，两条 `sh:` 动态变量赫然在目：

```yaml
HOST_ARCH:
  sh: '[ "$(uname -m)" = "x86_64" ] && echo "amd64" || echo "arm64"'
ANDROID_ABI:
  sh: '[ "$(uname -m)" = "arm64" ] && echo "arm64-v8a" || echo "x86_64"'
```

`uname`。一个外国口令——Unix 城邦的产物，用来问「你的机器是什么架构」。

问题不在 android 省。问题在：**这份登记簿是全局的**。`task` 编排器把各省的全局变量合并成一份，然后每唤醒一个器官，都要把这份登记簿从头到尾念一遍。

于是 Windows 城邦里的器官——`windows:build:helper`、`windows:build:dev`、`common:dev:frontend`——每次醒来，都得替远方那个从没来过 Windows 的 android 省，空喊两遍它自己的旧口令。

喊了，没人应答。`uname` 不在这座城邦的 PATH 里。

「不是三遍。」`task` 编排器对开发者说，「是**两遍一组**——两个变量，各喊一遍 `uname -m`。而你看着像三遍，是因为一次 `wails3 dev` 要苏醒四次，四组两遍叠在一起，糊成了一团。」

---

## 三 · 统一登记簿打穿了墙

「但这两遍口令，塔根本不需要答案。」`task` 编排器说，「Windows 的器官从不用 `HOST_ARCH`，也从不用 `ANDROID_ABI`。它们只是『顺便』念了念登记簿。」

这才是最阴的地方。

include 的「统一登记簿」本是为了省事——一个变量注册一次，全局可用，不用每个省各写一份。可这份便利有个代价：**它把省与省之间的墙打穿了**。android 省的探测口令，透过登记簿，成了全塔的起床仪式。墙本该隔离各省的方言，全局 vars 却让一省的方言响遍全塔。

修法不是拆掉登记簿，是**让塔念自己听得懂的母语**。go-task 的模板里本来就住着一位本地通译——`ARCH`（底层就是 Go 的 `runtime.GOARCH`，塔自己的语言）：

```yaml
HOST_ARCH:  '{{if eq ARCH "arm64"}}arm64{{else}}amd64{{end}}'
ANDROID_ABI: '{{if eq ARCH "arm64"}}arm64-v8a{{else}}x86_64{{end}}'
```

不再有 `uname`，不再有 `sh:` 探测。塔问自己，用自己听得懂的话。零外部命令，跨平台。

---

## 尾声

那两行 `"uname": executable file not found in $PATH` 从此再没出现过。

但 `task` 编排器记住了这个教训：每次它合并一份全局登记簿，它就等于在各省之间开了一道门。门开得越宽，一个省的老毛病就传得越远。

**缝**：include 合并的全局 `vars:` 是一扇没有门卫的门——android 省的架构探测口令 `uname`，透过这扇门成了全塔的起床仪式，Windows 的器官每次苏醒都要空喊两遍自己根本不认识的旧口令。统一登记的便利，正是方言串门的通道。

---

**教训**：全局登记簿，让一省的旧口令响遍全塔。
