# 第 01 区域 · 第 4 章 · 只改了一半的名字

> 区域归属：`01-解码与几何`（`frontend/src/utils/3d/adapters/vrm-bone-ui.ts` `vrm-adapter.ts` `vrm-bone.ts`）
> 时间线标签：vol-4
> 对应真实事件/代码改动：ADR-074 S3 把 `makeVrmBonePanelRenderer(vrm)` 抽成通用 `makeBonePanelRenderer(tree)`，但 `vrm-adapter.ts` 与 `vrm-bone-ui.test.ts` 仍 import 旧名，运行时崩 `does not provide an export named 'makeVrmBonePanelRenderer'`；改为 `makeBonePanelRenderer(buildVrmBoneTree(vrm))`

---

## 一 · 塔的黑屏

开发者按下刷新。

屏幕没有亮起来。控制台里躺着一行红字：

```
❌ 组件加载失败: The requested module '/src/utils/3d/adapters/vrm-bone-ui.ts'
does not provide an export named 'makeVrmBonePanelRenderer'
```

`vrm-bone-ui.ts` 明明在，文件明明有。但它说——它不再提供那个叫 `makeVrmBonePanelRenderer` 的东西了。

眼（`app-preview`）僵在原地。它想加载 VRM 的骨骼面板，手伸出去，摸到的是空的。

「那个名字……不存在了？」眼喃喃。

---

## 二 · 一个被改掉的名字

bus.js（心）翻开 `vrm-bone-ui.ts`。它找到了那个新名字：

```ts
export function makeBonePanelRenderer(tree: BoneTree | null): RenderVrmBonePanel {
  ...
}
```

`makeBonePanelRenderer`——通用的骨骼面板渲染器。ADR-074 S3 的活：从 VRM 专属抽成通用版，喂 `BoneTree` 而非 VRM，让 YSM 也能复用同一套骨骼面板。

改名的人干得很漂亮。函数签得干净，注释写得清楚，连「VRM 经 buildVrmBoneTree 构树后喂入」的用法都写进了注释。

但 bus.js 顺着血脉往下摸，摸到了两个还在喊旧名的地方：

```ts
// vrm-adapter.ts —— 还在喊旧名
import { makeVrmBonePanelRenderer } from "./vrm-bone-ui.ts";
```

```ts
// vrm-bone-ui.test.ts —— 也在喊旧名
import { makeVrmBonePanelRenderer } from "./vrm-bone-ui.ts";
```

旧名 `makeVrmBonePanelRenderer` 已经被擦掉了。但这两个呼喊者，还对着空气喊。

---

## 三 · 名字不是刻在一处，是缝在每一处

「所以是改名的错？」眼问。

「不。」bus.js 说，「错在——**改名的人以为名字只住在一个地方**。」

它摊开真相：一个函数名，不止「定义」在 `vrm-bone-ui.ts` 里，还「被引用」在每一个 import 它的地方。`vrm-adapter.ts` 喊它，测试喊它，未来的某处也会喊它。

名字不是一块刻在源头石碑上的字。名字是**一条缝在每一个呼喊者嘴边的链**。

改名的正确姿势，是顺着这条链，把所有呼喊旧名的嘴，一起换成新名：

```ts
// vrm-adapter.ts —— 喊新名，还要把 VRM 构树后喂进去
import { makeBonePanelRenderer } from "./vrm-bone-ui.ts";
import { buildVrmBoneTree } from "./vrm-bone.ts";

const renderer = makeBonePanelRenderer(buildVrmBoneTree(vrm));
```

改名的边界，比改名的那个文件大得多。**你改的是源头，但你欠下的，是每一处呼喊。**

---

## 尾声

眼后来想起那次黑屏。

不是函数坏了。是**名字断成了两半**——源头那一半已经变成了新的，呼喊者那一半还攥着旧的。两个半截名字之间，横着一条谁都看不见的裂缝，直到运行时，手一摸，空的。

**缝**：改名是一次边界跨越——名字同时活在「定义」与「所有引用」两处，改一半就断链。定义处的新名与调用处的旧名之间，隔着一条运行时才显形的裂缝。

---

**教训**：改名是条链，断一处全塔黑屏。
