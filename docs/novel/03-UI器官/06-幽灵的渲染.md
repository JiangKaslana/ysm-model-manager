# 第 03 区域 · 第 6 章 · 幽灵的渲染

> 时间线标签：vol-5
> 对应真实事件/代码改动：import-queue 按 ADR-040（≤400 行红线）薄壳拆分（`import-queue.ts` → `data/render/events` 三文件）后，`enqueueFile` 的队列渲染调用在拆分中丢失（注释还在、调用没了，`actions` 变量被吞成 return 字面量 → ReferenceError 被 catch 吞成 toast）；`remove` 处理器清空队列后缺 `toggleForm(false)`，拖拽区永不恢复。3 个既有测试因 waitFor 5 秒超时全部挂红。

---

码头上，墙上的字说"箱子入仓后，灯会亮"。

灯没有亮。

## 惊醒

搬运工把箱子搬进仓库——`dispatchDrop`，一只 `ysm.json` 落进拖拽区。入队逻辑跑了：`state.fileQueue.push(...)`，箱子进了清单；`showForm` 也跑了，表单从地下升起。一切看起来都在动。

可仓库的灯不亮。

`root.querySelectorAll(".dl-q-item")`——零。没有一盏灯。搬运工回头问钟表匠（那个叫 `waitFor` 的固执老头）：

"你在等什么？"

"等 `ScanModelEntriesWithLabel.mock.calls.length > 0`。"钟表匠盯着他的怀表，指针已经转过了 5000 毫秒，"它没有来。它永远不会来了。"

三个测试，三块怀表，五秒后齐齐熄灭。钟表匠说："不是我坏了。是**有些事情从未发生**。"

## 追查

外科医生沿着入队的路径往回走，停在一段注释面前：

```
// 渲染列表——通过 actions 回调（主文件注入）
// 注意：actions 在此处尚未声明，使用延迟绑定模式
// 加载仓库文件列表
if (!state.repoFiles) loadRepoFiles();
```

"三行注释，一行代码。"外科医生说，"注释说'渲染列表'。代码只做了'加载仓库文件列表'。**渲染的调用不在。**"

"那它去哪了？"

"看这个文件的结尾。"外科医生翻开 `import-queue-data.ts` 的最后一页。原本那里应该有一行 `const actions = { ... }`——一个被所有函数延迟引用的变量。可现在那里只剩一个 return 语句，`actions` 直接作为对象字面量塞进了返回值：

```ts
return {
  state,
  actions: { ... },  // const actions = { ... } 在哪？
  cleanup,
};
```

"`const actions` 没了。"外科医生说，"拆文件的时候，有人为了把这段代码挪进新文件，把变量声明和 return 合并了。注释还留在 `enqueueFile` 里，提醒后人'通过 actions 回调'——可 `actions` 这个名字，在整个作用域里已经不存在了。"

搬运工试着调用——`actions.renderImportedList?.()`——抛出一个 `ReferenceError: actions is not defined`。它还没来得及喊出声，就被 `readAndRouteFile` 的 catch 接住，吞进肚子里，变成一条温柔的 toast：

> "❌ 操作失败: actions is not defined"

"你看，"搬运工说，"连错误都学会了客气。"

## 真相

外科医生合上文件，沉默了很久。

"这不是你的错。也不是钟表匠的错。是**墙上的字**。"

"墙上的字？"

"注释。文档。`// 渲染列表——通过 actions 回调`——这句话本身没有错，它描述的是**设计意图**。可意图不是实现。拆分文件的时候，有人读到了注释，觉得'这里没问题'——因为注释还在，看起来一切正常。这就是我们的老朋友：**假设文档是对的**。它上一次以'CLI 解析器应该存在'的形式出现，这一次，它藏在一条注释里。"

码头管理员走过来，补充了第二个发现："还有一个更安静的。清空队列的时候——`fileQueue.splice(qi, 1)`，箱子搬走，清单清空——可拖拽区没有回来。`toggleForm(false)` 的调用在拆分时也丢了。用户删完最后一个箱子，会永远停在表单视图，面前是空荡荡的码头，回不去的入口。"

"两堵墙，两条缝。"外科医生数着，"400 行红线——为了守住它，我们拆了文件。墙守住了。可渲染调用和表单恢复，被留在了墙外面。"

## 教训

修复只有三行：把 `const actions = { ... }` 还回去，让延迟绑定恢复它的本来面目；在 `enqueueFile` 里补上那声一直没喊出来的渲染；给 `bindQueueEvents` 添一个 `toggleForm` 参数，让码头在空仓时重新张开入口。

三个测试亮起了灯。22/22，全绿。钟表匠收起怀表，什么也没说。

搬运工站在码头边，看着重新亮起的仓库，忽然明白了一件事：**注释不是实现。文档是墙上的字——字可以完美地描述一扇不存在的门。**

巴别塔的每一堵墙都刻着字。可字是别人刻的。字说"这里有一扇门"，不代表门存在；字说"这里安全"，不代表缝没开。系统要学的不是信任墙上的字，而是**亲手推一推每一扇被文字描述过的门**——推不动的那一扇，就是缝。

---

教训摘要：注释承诺的门，推不动才算数。
