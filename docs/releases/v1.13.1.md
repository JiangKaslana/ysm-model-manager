## 🧩 3D 动画：Molang 求值器落地（ADR-100）

自 v1.13.0 以来 3D 动画链路最大的一次补全：

| 改动 | 说明 |
|------|------|
| L4 Molang 求值器 | 内嵌 molangjs 表达式求值，关键帧真正动起来（乱飞根因修复） |
| 欧拉序 ZYX 判定 | 统一 `Rz×Ry×Rx` 顺序 + `eulerToQuaternion(-rx,-ry,+rz)` 角度取反，对齐游戏内 |
| cube 变换链三层 X 镜像 | origin/pivot/mesh localPos 三处对齐 Blockbench 活规范，修裙子/小部件朝向 |
| 动画位移口径 | 相对叠加 + X 取负 + scale=0 隐藏，对齐游戏内动画应用 |
| 切 clip 三通道平滑淡入 | L3 切 clip 淡入 + 未触及骨骼渐回 base + 全 clip 列表收录 |
| VMD 切换复位重播 | 切换动作先 `skeleton.pose()` 复位 + `action.reset()` 归零，防未覆盖骨骼残留旧动作末态 |
| 每组件独立纹理（ADR-114） | perComponent 分发，根治 texSlot 错位、minecart 采样错图 |
